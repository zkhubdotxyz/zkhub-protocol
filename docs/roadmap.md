# Roadmap

Phases describe order of work, not promised dates. Status labels are updated as things change.

## Phase 0: Foundation (done)
- [x] Landing site with live block, gas, TVL and pair data
- [x] Desktop shell: windows, dock, launcher, command palette
- [x] Launchpad market view
- [x] Local launch drafts, file manager, scheduler
- [x] Automated gates for logic, security and design rules

## Phase 1: Launch tooling (testing)
- [ ] Complete launch manifest format and validation
- [ ] Draft export and import
- [ ] Bundle scanner: same-block buys with shared funding
- [ ] Wallet association map on public transfer data
- [ ] Docs covering every program and data source

## Phase 2: Sealed launches (planned)
- [ ] Commit and clear contracts for the Sealed Book model
- [ ] Testnet-style dry runs with simulated participants
- [ ] Independent review of the contracts
- [ ] Dutch Descent and Lottery Allocation models

## Phase 3: Proofs (preview)
- [ ] Proof of fair clearing for a single batch
- [ ] Proof Explorer: receipts and public inputs
- [ ] Browser-side proving so inputs stay on the device
- [ ] Batch and recursive aggregation to reduce cost

## Phase 4: Ecosystem (planned)
- [ ] Token announcement with official contract and vesting details
- [ ] Staking, fee sharing and launch bonds
- [ ] Governance
- [ ] Swap and bridge routing
- [ ] Privacy levels beyond public

Each phase ends with a published write-up of what shipped and what did not.
